# Ultimate-Pazzle-Game
Game that I made in the School's Programming Language. It was made before I learned about arrays nor Functions

It is a Game that I made Using the School's Custom programming language. 

The game was made in january of 2024 as a random project that I made for fun. 

To Run the program you need the compiler of that language that can be found in this URL: [https://pseudo.gloglossa.gr/]
Runs best on Cromium based browsers 

The language is based in Pascal

---------[ To play it ]----------

1) bownload the .ps file
2) on the compiler open/upload the .ps file
3) Run code and test how visible the terminal is. You can adjust the size of the terminal by using the zoom in/out buttons in the top right (For the correct terminal size you must see the whole level + the level number at the top). Also you can abjust the terminal General browser zoom by using the Ctrl +/- (from expirience the best zoom is 150%)

4) play the game and keep the time that it took you
